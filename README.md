# Student Registration Form

Interactive student enrollment form with real-time client-side validation for email, phone, roll number, and course selection.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/student-registration-form.git
   cd student-registration-form
   ```
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox).
